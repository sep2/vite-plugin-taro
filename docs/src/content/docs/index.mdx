## 为现代 Taro 应用而生

<CardGrid stagger>
    <Card title="Vite 8 + React 19" icon="setting">
        基于 Vite 生态，一套代码同时构建微信小程序与 Web，不再依赖旧式 webpack 构建链路。
    </Card>
    <Card title="微信小程序热更新" icon="pencil">
        基于 Vite 模块图和 React Refresh，在修改组件时保留 App、页面、React 组件与输入状态。
    </Card>
    <Card title="Taro 组件与 API" icon="document">
        通过虚拟模块继续使用熟悉的 Taro 组件和 API，同时由插件负责不同目标的运行时解析。
    </Card>
    <Card title="Tailwind CSS v4" icon="open-book">
        默认模板开箱即用，工具类会自动适配微信小程序与 Web 样式输出。
    </Card>
</CardGrid>

## 支持目标

| 目标 | 开发方式 | 默认输出 |
| --- | --- | --- |
| 微信小程序（`wx`） | Vite 热更新 + 微信开发者工具 | `dist/wx` |
| Web（`h5`） | 标准 Vite 开发服务器 | `dist/h5` |
