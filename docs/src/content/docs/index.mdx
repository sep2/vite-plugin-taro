import { Card, CardGrid } from '@astrojs/starlight/components'

## 为现代微信小程序应用而生

<CardGrid stagger>
    <Card title="Vite 8" icon="rocket">
        由 Vite 8 和 Rolldown 驱动开发与生产构建，带来快速启动、增量构建和现代前端工具链。不再维护 Taro CLI 与旧式 webpack 构建配置。
    </Card>
    <Card title="React 19" icon="star">
        以 React 19 运行 App、页面和组件，可直接使用 Hooks、Suspense、`React.lazy()` 与现代组件模式。
    </Card>
    <Card title="微信小程序热更新" icon="pencil">
        基于 Vite 模块图和 React Refresh，在修改组件时保留 App 数据、当前页面、深层 React 组件与输入状态。
    </Card>
    <Card title="全自动分包" icon="puzzle">
        只需通过动态 `import()` 按需加载功能，vpt 自动规划主包与代码分包，跨包引用不受微信分包规则限制，共享模块也不会重复打包。
    </Card>
    <Card title="Taro 组件与 API" icon="document">
        继续使用熟悉的 Taro 组件和 API，完全兼容 Taro。
    </Card>
    <Card title="微信原生组件" icon="puzzle">
        支持原生组件，和 React 互相调用，并且参与全自动分包。
    </Card>
    <Card title="Skyline 渲染模式" icon="mobile-android">
        支持全局或按页面启用 Skyline 模式，获得更流畅的渲染体验。
    </Card>
    <Card title="Tailwind CSS v4" icon="open-book">
        默认模板开箱即用，工具类会自动适配微信小程序与 Web 样式输出。
    </Card>
</CardGrid>
