# vite-plugin-taro-runtime

## 0.8.1

### 变更

- fa2b4450：内置 Taro 从 `4.3.0` 升级至 `4.3.1`，同步 Taro React 渲染器、平台适配包与运行时补丁。
- fa2b4450：节点插入在移动节点或消费 DocumentFragment 前校验引用节点，非法引用保持源树、目标树、事件索引及更新队列不变。

### 升级说明

从 `0.8.0` 升级到 `0.8.1`：运行时随 `vite-plugin-taro@0.8.1` 自动升级。应用中如直接声明了运行时依赖，请同步执行：

```sh
pnpm add --save-exact vite-plugin-taro-runtime@0.8.1
```

插件与运行时统一使用 `0.8.1`，完成依赖升级后重新构建应用。

## 0.8.0

### 新增与改进

- 90e73eb1、11f2847b、4d15cdda：提供页面渲染上下文、原生节点克隆委托及挂载与生命周期衔接，支撑微信、抖音 DOM 渲染。
- 16869643、e562c488：批量转发 React 样式更新；同级节点重排复用原生节点，保留 React 状态、ref 和事件。
- 767f5264、9ef5fbff、766a5fed：回调替换时保留原生事件订阅，使用 SDK 提供的事件目标数据，并优化子树事件索引清理。
- d0c458fb、981aab17、1308a145：按需生成 MutationObserver 记录，将模板序列化与属性分类限定在模板渲染链路。
- 6b291f21、d554043a、09611bce：按需分配样式与事件处理表，优化模板上下文查找，减少 DOM 模式下的分配与遍历。
- bc6e98df、96ee29ff：修复带厂商前缀的样式属性访问，以及移除未注册监听器时的事件处理。

### 升级说明

从 `0.7.13` 升级到 `0.8.0`：运行时随 `vite-plugin-taro@0.8.0` 自动升级，通常无需单独安装。应用中如直接声明了运行时依赖，请同步执行：

```sh
pnpm add --save-exact vite-plugin-taro-runtime@0.8.0
```

现有 Taro/React 组件调用方式保持兼容；请同时升级插件与运行时，使用同一稳定版本。
