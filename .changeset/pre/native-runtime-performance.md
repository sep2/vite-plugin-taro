### 升级说明

从 `0.7.13` 升级到 `0.8.0-beta.0`：运行时随 `vite-plugin-taro@0.8.0-beta.0` 自动升级，通常无需单独安装。应用中如直接声明了运行时依赖，请同步执行：

```sh
pnpm add --save-exact vite-plugin-taro-runtime@0.8.0-beta.0
```

现有 Taro/React 组件调用方式保持兼容；请同时升级插件与运行时，使用同一 beta 版本。
